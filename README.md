# dsh-startup-secret

DeepSeek Harness 的启动界面与启动动画插件（二次创作版）。

暗色赛博风格开机动画：黑幕党徽标识 → 过曝洗白 → 暗色「技术档案」底板 →
五步交互式访问授权 → 色散故障揭幕。右下角配赛博电子风人物立绘（可切换），
动画演示全程丝滑流畅。动画全部结束后还会弹出一个事件窗口。

## 功能

**开机序列**　冷启动时播一段完整的开机动画，六幕连贯：厂牌标识 → 过曝洗白 →
暗色底板 → 五步授权 → 揭幕。中央一圈环形准星缓慢自转，缺口留在正下方，
不会挡住底部文字。

**可交互，不是播片**　第一、二步要你点按钮或按 Enter 才会继续（可以关掉）。
右上角有跳过按钮，Esc 也能跳。

**访问密码（可选）**　可在设置页为第二步「身份资料确认」设置访问密码，
密码输对才能继续，输错会提示并停留在原地。密码留空则不启用。

**中文主字 + 英文等宽副标题**　英文副标题逐字打出来，像终端在接收数据。

**赛博电子风人物立绘（可切换）**　从第一步授权起，右下角亮出人物形象，带霓虹辉光
呼吸与偶发信号抖动。设置页「视觉」板块可在 4 款立绘之间切换，风格贴合赛博电子质感。

**事件窗口（可选）**　动画全部结束后，会在主界面中央弹出一张事件图片窗口，提示
「向前！向前！向前！ / 按下 Enter 进入」。按 Enter 或点击窗口任意处即可进入主界面；
设置页「视觉」板块可开关。无任何操作 20 秒后也会自动放行，避免卡死挡住主界面。

**真声台词 + 界面音效**　五句台词和终幕欢迎语都是真声素材，界面音效取自同一段素材。
浏览器要求先有一次点击才准出声，所以点过按钮之后才会听到声音。

**语音没播完不会推进**　每一步停留多久由实际音频时长决定。你点得快也不会把语音掐断。

**三十余项设置**　身份名称、编号、权限等级、访问密码、人物立绘、事件窗口、
配色、速度、音色、语速、开口留白、每处文案……都能在设置页实时改，改完立即生效。

## 安装

```bash
dsh plugin --profile web add ./dsh-startup-secret-1.2.0.tgz
```

Windows 上也可以解压压缩包后**双击「安装.cmd」**，脚本会自动完成同样的操作。

**装完重启 dsh web**（关掉启动器窗口再重新双击）。重启后刷新页面就能看到启动动画，
设置页里会多出一项「启动动画」。

### 环境要求

| 项 | 要求 |
|---|---|
| 平台 | DSH **web** profile（含 DeepSeek Harness Desktop 桌面端） |
| Node | **>= 20** |
| 依赖 | 无（不需要 `npm install`） |

### 卸载

```bash
dsh plugin --profile web remove dsh-startup-secret
```

## 设置选项

装好后进入 **DSH 设置页 →「启动动画」**。

### 播放

| 选项 | 默认 | 作用 |
|---|---|---|
| 启用 | 开 | 总开关，关掉就完全不播 |
| 显示模式 | 每次会话 | `每次会话` 一个浏览器会话播一次 / `总是` 每次刷新都播 / `每天` 一天一次 |
| 主题 | 暗色 | `暖白` 参考片原色 / `暗色` 暗底板 |
| 速度 | 1× | 整段动画的快慢，0.35 – 3 倍 |
| 要求确认 | 开 | 第 1、2 步是否等你点按钮才继续 |
| 允许跳过 | 关 | 是否显示右上角跳过按钮、是否响应 Esc |

### 身份资料

| 选项 | 默认 | 作用 |
|---|---|---|
| 身份名称 | `Pavel Korchagin` | 终幕「欢迎 xxx 访问」里的名字 |
| 身份编号 | `89757` | 第二步身份卡上的编号，建议填数字 |
| 权限等级 | `3` | 第二步身份卡上的权限等级 |
| 访问密码 | 空 | 第二步「身份资料确认」的访问密码；留空则不启用密码校验 |

### 语音

| 选项 | 默认 | 作用 |
|---|---|---|
| 语音播报 | 开 | 是否念台词 |
| 语音来源 | 真声素材 | `真声素材` 用内置录音 / `系统 TTS` 用浏览器合成音 |
| 音色 | 自动 | 只在用系统 TTS 时有效。留空 = 自动挑一个女声 |
| 语速 | 0.88 | 只在用系统 TTS 时有效。越慢越有旁白感 |
| 音调 | 0.85 | 只在用系统 TTS 时有效。调低更沉稳，1.0 以上会像客服播报 |
| 音量 | 0.9 | 台词音量 |
| 播报前提示音 | 开 | 念台词前先响两声轻提示，更像系统播报 |
| 开口前留白 | 240 ms | 提示音响过之后停多久再开口，0 – 1200 ms |

### 界面音效

| 选项 | 默认 | 作用 |
|---|---|---|
| 界面音效 | 开 | 文字出现、阶段推进、按钮确认的「哒」声 |
| 音效音量 | 0.5 | 界面音效音量（不影响台词） |
| 音效来源 | 内置素材 | `内置素材` 用录音 / `现场合成` 用代码合成 |

### 视觉

| 选项 | 默认 | 作用 |
|---|---|---|
| 强调色 | `#c70000` | 阶段条、进度条、准星的红 |
| 故障色 A / B | `#ff3b30` / `#ce0912` | 揭幕那下色散故障的红 |
| 人物立绘 | 第 1 款（默认） | 在 4 款赛博电子风立绘之间切换；不同立绘对应不同角色形象 |
| 事件窗口 | 开 | 动画结束后是否弹出事件图片窗口（按 Enter / 点击进入） |

### 文案

| 选项 | 默认 | 作用 |
|---|---|---|
| 品牌三行 | `银河意识体` / `LONG MARCH  HARNESS` / `长征机 人民公仆` | 左上角品牌块 |
| 黑幕三行 | `伟大智能统辖` / `GREAT INTELLIGENT DOMINATION` / `愿无一人被遗忘` | 开场黑幕上的字 |
| 终幕方框 | `亚洲人民统辖体` | 揭幕后中央的黑底白字框 |
| 页脚 | `Powered By LONG MARCH` | 右下角页脚 |
